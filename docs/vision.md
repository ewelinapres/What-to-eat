# Wizja

Kilka razy dziennie stajemy przed pytaniem "Co dzisiaj zjeść?". Czasami znalezienie posiłku, który zaspokoiłby nasze zachcianki zajmuje zbyt dużo czasu.

Rozwiązaniem tego problemu będzie zaproponowana przez nas aplikacja. Dzięki krótkiej ankiecie zbierane będą informacje o aktualnych preferencjach odbiorcy, a następnie na tej podstawie generowana będzie lista kilku potencjalnych posiłków.

Podstawowa aplikacja będzie zawierała ograniczoną liczbę dań, którą użytkownicy będą mogli rozszerzać o swoje propozycje.
